Behavior: Capability Statements

The following artifacts define the specific capabilities that different types of systems are expected to have in order to comply with this implementation guide. Systems conforming to this implementation guide are expected to declare conformance to one or more of the following capability statements.

Capacidades para Cliente MHD

CapabilityStatement que define las capacidades requeridas para los sistemas cliente que interactúan con el MHD Responder definido por esta guía.

El cliente implementa las funciones de Document Source y Document Consumer definidas por IHE MHD 4.2.2, adaptadas a los perfiles y restricciones de esta implementación local.

El cliente puede publicar documentos mediante ITI-65, consultar SubmissionSets mediante ITI-66, localizar referencias documentales mediante ITI-67 y recuperar documentos mediante ITI-68.
MHD Responder

CapabilityStatement que define las capacidades requeridas para un servidor MHD conforme a la Guía MHD para HSI.

El servidor implementa las funciones de Document Recipient y Document Responder definidas por IHE MHD 4.2.2, adaptadas a los perfiles locales de esta guía.

Structures: Resource Profiles

These define constraints on FHIR resources for systems conforming to this implementation guide.

BundleMhd

Perfil asociado al bundle de transacciones MHD, considerando la asociación de documentos de tipo IPS, referenciados a la Guía Core Argentna AR.FHIR.CORE
ListMhd

Perfil asociado al listado de documentos referenciados para HSI en un modelo MHD
ReferenciaDocumental

Perfil asociado al la refetrencia documental para HSI en un modelo MHD, consderado para transacciones asociadas a una ITI-65 e ITI-67. Se considera en el perfil la asociación de documentos de tipo IPS, referenciados a la Guía Core Argentna AR.FHIR.CORE

Terminology: Value Sets

These define sets of codes used by systems conforming to this implementation guide.

Categorías de Documento Clínico para DocumentReference

Categorías generales de documentos clínicos codificadas en LOINC para ser usadas en DocumentReference.category.
Tipos de Documento Clínico para DocumentReference

Tipos documentales clínicos codificados en LOINC para ser usados en DocumentReference.type.
