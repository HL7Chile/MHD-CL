DocumentReference.content S This element must be supported. 1..1 BackboneElement Contenido del documento (IPS u otro) nacional referenciado con url reltiva en caso de ser X-Road, o url absoluta en caso de ser un repositorio FHIR. Se define como un campo obligatorio, y se recomienda usar el valor 'Attachment' para indicar que el contenido del documento referenciado es un archivo adjunto que contiene el documento clínico en formato digital.
DocumentReference.content.attachment S This element must be supported. 1..1 Attachment Definición del archivo adjunto que contiene el documento referenciado
DocumentReference.content.attachment.contentType S This element must be supported. 1..1 code Mime type of the content, with charset etc.
Required Pattern: application/fhir+json (extensions allowed)
DocumentReference.content.attachment.url S This element must be supported. 1..1 url URL del archivo adjunto que contiene el documento referenciado, en formato FHIR IPS, Binary IPS u otro documnento en esos formatos.
Example Ejemplo de IPS referenciado en X-Road: /pba/tndXroad/santamarina/docs/ips-xxx
DocumentReference.content.attachment.hash S This element must be supported. 0..1 base64Binary Hash del archivo adjunto que contiene el documento IPS nacional referenciado
DocumentReference.content.attachment.title S This element must be supported. 0..1 string Título del archivo adjunto que contiene el documento referenciado
Example Ejemplo de Título del documento contenido referenciado via X-Road: IPS-001
