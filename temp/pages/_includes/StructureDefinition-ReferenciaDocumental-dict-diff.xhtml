2. DocumentReference.masterIdentifier
Definition

Identificador único para el documento IPS nacional referenciado. Se define como el identificador principal del docunento, el cual debe ser un identificador absoluto, único e irrepetible en el domino en donde ha sido almacenado

ShortIdentificador único para el documento IPS nacional referenciado. Es el identificador principal del IPS
Must Supporttrue
ExampleEjemplo de identificador maestro: { "system" : "https://repositorio.cl/documentos/ips", "value" : "IPS-2026-00001" }
4. DocumentReference.identifier
Definition

Identificador alternativo para el documento IPS nacional referenciado. Se usa comunmente cuando el document se ha almacenado en varios dominios, y cada uno de ellos le ha asignado un identificador diferente.

ShortIdentificador alternativo para el documento IPS nacional referenciado. Es un identificador secundario del IPS
NoteThis is a business identifier, not a resource identifier (see discussion)
6. DocumentReference.identifier:entryUUID

NoteThis is a business identifier, not a resource identifier (see discussion)

8. DocumentReference.status
Definition

Estado de la referncia. Se define como un campo obligatorio, y se recomienda usar el valor 'current' para indicar que el documento referenciado es el más actualizado de los disponibles.

ShortEstado de la referencia al documento IPS: current|superseded|entered-in-error
Must Supporttrue

Definition

Autor del documento o IPS nacional referenciado. Se define como un campo opcional, y se recomienda usar el valor 'Practitioner' para indicar que el autor del documento referenciado es un profesional de la salud.

ShortAutor del documento o IPS nacional referenciado

38. DocumentReference.securityLabel
Definition

Etiqueta de seguridad del documento IPS nacional referenciado. Se define como un campo opcional, y se recomienda usar el valor 'CodeableConcept' para indicar la etiqueta de seguridad del documento referenciado.

40. DocumentReference.content
Definition

Contenido del documento (IPS u otro) nacional referenciado con url referencial. Se define como un campo obligatorio, y se recomienda usar el valor 'Attachment' para indicar que el contenido del documento referenciado es un archivo adjunto que contiene el documento clínico en formato digital.

ShortContenido del documento (IPS u otro) nacional referenciado con url reltiva en caso de ser X-Road, o url absoluta en caso de ser un repositorio FHIR. Se define como un campo obligatorio, y se recomienda usar el valor 'Attachment' para indicar que el contenido del documento referenciado es un archivo adjunto que contiene el documento clínico en formato digital.
Must Supporttrue
42. DocumentReference.content.attachment
Definition

Definición del archivo adjunto que contiene el documento (IPS u otro) nacional referenciado. Se define como un campo obligatorio, y se recomienda usar el valor 'Attachment' para indicar que el contenido del documento referenciado es un archivo adjunto que contiene el documento clínico en formato digital.

ShortDefinición del archivo adjunto que contiene el documento referenciado

ShortHash del archivo adjunto que contiene el documento IPS nacional referenciado

ShortTítulo del archivo adjunto que contiene el documento referenciado

ShortPeriodo de tiempo al que se refiere el documento IPS nacional u otro referenciado
