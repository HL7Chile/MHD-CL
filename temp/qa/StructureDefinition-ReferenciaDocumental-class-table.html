DocumentReference : DocumentReference
Perfil asociado al la refetrencia documental para HSI en un modelo MHD, consderado para transacciones asociadas a una ITI-65 e ITI-67. Se considera en el perfil la asociación de documentos de tipo IPS, referenciados a la Guía Core Argentna AR.FHIR.CORE
masterIdentifier S This element must be supported. 1 .. 1 UniqueIdIdentifier Identificador único para el documento IPS nacional referenciado. Es el identificador principal del IPS
Ejemplo Ejemplo de identificador maestro: {"system":"https://repositorio.cl/documentos/ips","value":"IPS-2026-00001"}
identifier 0 .. * Identifier Identificador alternativo para el documento IPS nacional referenciado. Es un identificador secundario del IPS
status S This element must be supported. 1 .. 1 code Estado de la referencia al documento IPS: current|superseded|entered-in-error
type 1.. 1 CodeableConcept Tipo de documento referenciado
Binding: Tipos de Documento Clínico para DocumentReference ( extensible )
category 1.. 1 CodeableConcept Categoría del documento referenciado
Binding: Categorías de Documento Clínico para DocumentReference ( extensible )
subject 1.. 1 Reference ( CL Paciente ) Paciente al que se refiere el documento IPS nacional referenciado
date 1.. 1 instant Fecha de creación del documento IPS nacional referenciado
author 1.. * Reference ( Practitioner | PractitionerRole | Organization | Device | Patient | RelatedPerson ) Autor del documento o IPS nacional referenciado
securityLabel 0 .. * CodeableConcept Etiqueta de seguridad del documento IPS nacional referenciado
content S This element must be supported. 1 .. 1 BackboneElement Contenido del documento (IPS u otro) nacional referenciado con url reltiva en caso de ser X-Road, o url absoluta en caso de ser un repositorio FHIR. Se define como un campo obligatorio, y se recomienda usar el valor 'Attachment' para indicar que el contenido del documento referenciado es un archivo adjunto que contiene el documento clínico en formato digital.
context S This element must be supported. 1.. 1 BackboneElement Contexto del documento IPS nacional u otro referenciado
