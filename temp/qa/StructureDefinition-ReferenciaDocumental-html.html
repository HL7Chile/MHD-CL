DocumentReference.content S This element must be supported. Contenido del documento (IPS u otro) nacional referenciado con url reltiva en caso de ser X-Road, o url absoluta en caso de ser un repositorio FHIR. Se define como un campo obligatorio, y se recomienda usar el valor 'Attachment' para indicar que el contenido del documento referenciado es un archivo adjunto que contiene el documento clínico en formato digital.
DocumentReference.content.attachment S This element must be supported. Definición del archivo adjunto que contiene el documento referenciado
DocumentReference.content.attachment.contentType S This element must be supported. Required Pattern: application/fhir+json (extensions allowed)
DocumentReference.content.attachment.url S This element must be supported. URL del archivo adjunto que contiene el documento referenciado, en formato FHIR IPS, Binary IPS u otro documnento en esos formatos.
Example Ejemplo de IPS referenciado en X-Road: /pba/tndXroad/santamarina/docs/ips-xxx
