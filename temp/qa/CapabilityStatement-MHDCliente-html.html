Note to Implementers: FHIR Capabilities

Any FHIR capability may be 'allowed' by the system unless explicitly marked as 'SHALL NOT'. A few items are marked as MAY in the Implementation Guide to highlight their potential relevance to the use case.

This CapabilityStatement instantiates these CapabilityStatements Document Source (publisher), Document Consumer (client)

SHALL Support the Following Implementation Guides

  • http://mhd.ri.hsisalud.org/ImplementationGuide/fhir.mhdig

FHIR RESTful Capabilities

Mode: client

Cliente MHD local que permite publicar, localizar y recuperar documentos clínicos mediante las transacciones definidas por IHE MHD y los perfiles definidos por esta guía.

Security

Las comunicaciones deben realizarse mediante HTTPS y utilizar los mecanismos de autenticación, autorización, control de acceso, auditoría y trazabilidad definidos para la infraestructura local.

Summary of System-wide Interactions
  • Supports the transactioninteraction described as follows:

    ITI-65 Provide Document Bundle.

    El cliente SHALL poder generar y enviar un Bundle transaction conforme al perfil BundleMhd definido por esta guía:

    http://mhd.ri.hsisalud.org/StructureDefinition/BundleMhd

  • Supports the search-systeminteraction described as follows:

    El cliente puede realizar búsquedas a nivel de sistema conforme a las capacidades definidas para el Document Consumer de IHE MHD.
