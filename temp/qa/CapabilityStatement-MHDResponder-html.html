Note to Implementers: FHIR Capabilities

Any FHIR capability may be 'allowed' by the system unless explicitly marked as 'SHALL NOT'. A few items are marked as MAY in the Implementation Guide to highlight their potential relevance to the use case.

FHIR RESTful Capabilities

Mode: server

Servidor MHD local que permite registrar, consultar y recuperar documentos clínicos utilizando las transacciones definidas por IHE MHD y los perfiles definidos por esta guía.

Security

Las transacciones deben realizarse mediante HTTPS y aplicar los mecanismos de autenticación, autorización, control de acceso, auditoría y trazabilidad definidos para la infraestructura.
